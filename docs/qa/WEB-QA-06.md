displayed product count is `1` once hydrated; the HTML text before hydration reads `0`, by design (see the
comment in `MetricsSection.astro`; rule C9 reads `data-product-count`).

`src/lib/case-studies.ts:27-30` filters `getPublishedCaseStudies()` (which drops `draft: true` outside dev)
on `kind === "product"`. With `annuaire-lingerie-africa` published and `exemple` a draft, the count is 1.
Gate rule C9 also passes (count equals the product case studies in `dist/`).

**PASS**

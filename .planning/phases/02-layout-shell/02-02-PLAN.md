    **Button.astro** (per D-16, D-17, D-18 and UI-SPEC):

    Props interface:
    ```typescript
    interface Props {
      variant?: "primary" | "ghost";
      size?: "default" | "small";
      href?: string;
      class?: string;
    }
    ```
    Destructure with defaults: `const { variant = "primary", size = "default", href, class: className = "" } = Astro.props;`

    Class composition:
    - Base: `"inline-flex items-center justify-center gap-2 rounded-lg font-semibold transition-colors duration-200"`
    - Variant `primary`: `"bg-accent text-white hover:bg-[#2E6A8F]"`
    - Variant `ghost`: `"bg-transparent border border-accent text-accent hover:bg-accent/10"`
    - Size `default`: `"h-12 px-6 text-base"`
    - Size `small`: `"h-9 px-4 text-sm"`

    Compose with `class:list={[baseClasses, variantClasses[variant], sizeClasses[size], className]}`.

    Conditional rendering: If `href` is provided, render `<a>`. Otherwise render `<button>`. Astro does NOT support dynamic tag names (`<Tag>` pattern) — use explicit conditional:
    ```
    {href ? (
      <a href={href} class:list={classes}>
        {Astro.slots.has("icon") && <span class="inline-flex shrink-0"><slot name="icon" /></span>}
        <slot />
      </a>
    ) : (
      <button class:list={classes}>
        {Astro.slots.has("icon") && <span class="inline-flex shrink-0"><slot name="icon" /></span>}
        <slot />
      </button>
    )}
    ```

    Icon slot (per D-17): Named slot `"icon"` renders left of text content. Only shown when the slot is populated (`Astro.slots.has("icon")`).

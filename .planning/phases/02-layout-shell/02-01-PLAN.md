    **Scoped styles** for nav states:
    ```css
    /* Default state: transparent over dark background */
    .nav-link { color: white; }
    .nav-link:hover { color: rgba(255, 255, 255, 0.8); }

    /* Active link indicator: 2px accent underline per D-03 */
    .nav-link.active::after {
      content: "";
      position: absolute;
      bottom: -4px;
      left: 0;
      right: 0;
      height: 2px;
      background-color: var(--color-accent);
    }

    /* Scrolled state: solid background, different hover/logo colors */
    :global(#navbar.scrolled) { background-color: rgba(27, 42, 74, 0.95); backdrop-filter: blur(4px); }
    :global(#navbar.scrolled) .nav-link:hover { color: var(--color-accent); }
    :global(#navbar.scrolled) .nav-logo { color: var(--color-accent); }
    ```

    Note: Use `:global()` for the `#navbar.scrolled` selector since the `scrolled` class is toggled by JavaScript on the `<nav>` element. Scoped styles would mangle the class name.

    **Inline script** (per D-05) for IntersectionObserver scroll detection:
    ```html
    <script is:inline>
      (() => {
        const nav = document.getElementById('navbar');
        const sentinel = document.getElementById('nav-sentinel');
        if (!nav || !sentinel) return;
        const observer = new IntersectionObserver(
          ([entry]) => {
            nav.classList.toggle('scrolled', !entry.isIntersecting);
          },
          { threshold: 0 }
        );
        observer.observe(sentinel);
      })();
    </script>
    ```
    MUST use `is:inline` to prevent Astro from bundling/deferring the script, which would cause a flash of wrong navbar state. The sentinel element (`#nav-sentinel`) is placed in BaseLayout.astro.

    **Create `src/components/ui/MobileMenu.tsx`** — a React island providing mobile hamburger menu with full-screen overlay.

    Per D-13: Full-screen overlay on dark bg-primary (#1B2A4A) background with nav links centered vertically.
    Per D-14: Just the 4 nav links (Expertises, Produits, Experiences, Idees & Opinions) — clean and focused.
    Per D-15: When a nav link is tapped, menu closes immediately then smooth-scrolls to the section.
    Per D-16: Hamburger icon smoothly morphs into X when menu is open. 3 bars, top rotates 45deg, middle fades, bottom rotates -45deg. Duration 300ms ease-in-out.
    Per D-17: Hydrated with client:media="(max-width: 768px)" — zero JS on desktop.
    Per D-19: LazyMotion + m component pattern for overlay animation.
    Per D-20: Import from motion/react.

    Props interface:
    ```typescript
    interface NavLink {
      label: string;
      href: string;
    }
    interface MobileMenuProps {
      links: NavLink[];
    }
    ```

    Implementation structure:
    - `useState` for `isOpen` boolean.
    - `useRef` for overlay container (focus trap target).
    - Import `{ LazyMotion, domAnimation } from "motion/react"` and `* as m from "motion/react-m"`.

    **Hamburger button:**
    - Render a `<button>` with 3 `<span>` elements as bars inside a flex column with gap.
    - Bar styles: `block w-5 h-0.5 bg-white transition-all duration-300 ease-in-out`.
    - When `isOpen`:
      - Bar 1: `translate-y-[7px] rotate-45` (moves down to center + rotates).
      - Bar 2: `opacity-0` (fades out).
      - Bar 3: `-translate-y-[7px] -rotate-45` (moves up to center + rotates opposite).
    - Button: `md:hidden` class (only visible on mobile), `w-11 h-11` for 44px tap target (per WCAG), `flex flex-col justify-center items-center gap-[6px]`.
    - `aria-label`: "Ouvrir le menu" when closed, "Fermer le menu" when open.
    - `aria-expanded={isOpen}`.

    **Overlay:**
    - Wrap in `<LazyMotion features={domAnimation}>`.
    - Use `<m.div>` with `initial={{ opacity: 0, y: -20 }}`, `animate={{ opacity: 1, y: 0 }}`, `exit={{ opacity: 0, y: -20 }}`, `transition={{ duration: 0.2 }}`.
    - Wrap in `<AnimatePresence>` (import from `motion/react`) for exit animation.
    - Overlay classes: `fixed inset-0 z-50 flex flex-col items-center justify-center` with `style={{ backgroundColor: "#1B2A4A" }}`.
    - Nav links: `<a>` elements with classes `text-xl font-semibold text-white hover:text-white/80 transition-colors duration-200`, arranged in flex column with `gap-6` (24px).
    - `aria-label="Menu de navigation principal"` on the overlay nav element.

    **Link tap handler:**
    - On click, immediately set `isOpen = false`.
    - The browser will then follow the anchor href which triggers smooth scroll (CSS `scroll-behavior: smooth` is already in place from Phase 3).

    **Body scroll lock:**
    - `useEffect` watching `isOpen`: when true, add `overflow: hidden` to `document.body.style`. When false (or cleanup), restore `overflow` to empty string.

    **Escape key:**
    - `useEffect` watching `isOpen`: when true, add `keydown` listener on `document` that calls `setIsOpen(false)` if `e.key === "Escape"`. Cleanup removes listener.

    **Focus trap:**
    - Implement `useFocusTrap` custom hook as described in research:
      - When `isOpen` and overlay ref exists, query all focusable elements inside (`a[href], button:not([disabled])`).
      - Focus the first element on open.
      - On Tab at last element, wrap to first. On Shift+Tab at first, wrap to last.
      - On close, return focus to the hamburger button (store button ref).

    Export as default function component.

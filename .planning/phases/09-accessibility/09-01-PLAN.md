In src/styles/global.css, make two changes:

1. **Color contrast fix (per D-01, D-02):** Change `--color-accent: #3A7CA5` to `--color-accent: #336D93` inside the `@theme` block. This darkened accent achieves 5.31:1 contrast on bg (#F8F9FA) and 5.60:1 on white, satisfying WCAG AA 4.5:1 minimum. The old value (#3A7CA5) only achieved 4.32:1 on bg, which fails. All components using `text-accent`, `bg-accent`, `border-accent` inherit this fix automatically via the token.

2. **Global focus ring base styles (per D-04, D-05, D-06):** Add an `@layer base` block after the existing CSS rules. This provides default focus-visible ring styling for all interactive elements on light backgrounds:

```css
@layer base {
  a:focus-visible,
  button:focus-visible {
    outline: none;
    box-shadow: 0 0 0 2px var(--color-bg), 0 0 0 4px var(--color-accent);
    border-radius: 0.25rem;
  }
}
```

The `box-shadow` creates a 2px accent ring with 2px bg-colored offset gap. Components on dark backgrounds (Footer, Navbar) will override with white ring in Plan 02. Using `focus-visible` (not `focus`) per D-05 to avoid showing ring on mouse clicks.

Do NOT modify the animation CSS or font import -- leave everything else unchanged.
